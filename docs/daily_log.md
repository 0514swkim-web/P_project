- 실시간 데모 `live_demo.py` 구현: 모드·HOLD·클러치 게이지·손가락별 각도 막대를 화면에 표시. 내장 웹캠 실측 인식 16ms, 판별 0.035ms
- 환경 문제 해결: mediapipe import 실패 발견(스마트 앱 컨트롤이 matplotlib 3.11.2 DLL 차단) → 3.10.9로 변경. 그동안 수집·환경 확인 스크립트도 실행 불가 상태였음
- 녹화 준비: `--record` 옵션, 촬영 목록(A~F)과 순서, 아이패드용 체크리스트
- 야외 녹화(직접): 조명 조절이 안 되는 곳, 약 10 FPS. A 기본 손 모양(113초), B 엄지(80초), D 조작 시나리오(96초)
- 튜닝 #1: 녹화 분석으로 문제 5건 수정(엄지 거리 0.75, 엄지 신뢰도 계산, V자 엄지 무관, OK 조건, 손 끊김 0.3초). 고른 25프레임 기준 의도대로 판정 7 → 20. 테스트 61개 통과
- 녹화 캡처 정리: 손 모양별 대표 장면 15장 + 한눈에 보기(얼굴 제외, 손·패널만). `recordings/captures/`와 노션 튜닝 #1 페이지에 첨부
- GitHub 공개 준비: 저장소 이름 `P_project`(공개)로 결정. 저장소 문서·HTML·PDF의 실명을 역할 이름(팀원A·B·C, 지도교수 등)으로 바꾸고, push 전 기존 커밋 4개도 실명을 뺀 이력으로 다시 만듦(`mask-tmp` 브랜치, 원본은 `backup/before-mask`). 커밋·push는 직접 진행
- 기록 체계: `docs/tuning_log.md`, `--log` CSV에 손가락 원시 값, 노션 "P프로젝트 구현 현황"(변경 기록·일일 진행 기록), 구 노션 페이지 통합, "전체 흐름과 앞으로 할 일" 페이지(남은 일정·주차별 진행 방법)

**결정**
- 조명 조절이 안 돼도 야외에서 A·B·D 진행 (정지 자세의 손가락 각도는 FPS와 무관). FPS 영향을 받는 C·E·F는 실내로
- V자는 엄지를 접든 펴든 V자로 판정
- 손이 잠깐 안 보여도 0.3초까지는 모드 유지(즉시 위치 고정) → 팀 공유 필요

**문제·배운 점**
- 어두우면 웹캠이 스스로 FPS를 10까지 낮춤
- 엄지는 각도가 아니라 검지 뿌리와의 거리로 구분됨 (접힘 0.24~0.56, 펴짐 0.97~1.45)
- 녹화 영상에 뼈대가 그려져 있어 MediaPipe로 다시 분석할 수 없었음 → 다음부터 `--log`를 같이 켜기
- 남은 문제 R1~R4 (주먹↔엄지 척, V자 약지·소지, OK 샘플 부족, 야외 10 FPS)
